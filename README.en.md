# Facebook Ad Library Guide (Chinese)

A 20-chapter guide to the **Facebook Ad Library (Meta Ad Library)**: how to find competitors' ads, read ad cards, spot winning ads, save creatives and research ads by product category and market. Written in Simplified Chinese for cross-border e-commerce and DTC teams. This page gives English titles and summaries.

## Quick answers

| Question | Answer |
|:--|:--|
| Where is it, do I need to log in? | `https://www.facebook.com/ads/library/`. Usually no login or ad account needed. |
| Open one ad directly | `https://www.facebook.com/ads/library/?id=LIBRARY_ID` |
| All ads of one Page | add `search_type=page&view_all_page_id=PAGE_ID` |
| Can I see spend? | Not for regular commercial ads. Political/issue ads and ads delivered in the EU disclose reach data. |
| Are stopped ads still visible? | Regular ads usually disappear; EU-delivered ads stay about a year. |
| Is it a winning ad? | Long run time, many ads using the same creative, multiple versions, repeated variants of one angle, several Pages running the same product. |
