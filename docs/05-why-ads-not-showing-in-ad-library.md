# 为什么在广告资料库里搜不到某个主页或广告

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《为什么在广告资料库里搜不到某个主页或广告》的精简版，完整图文版见文末链接。

搜不到或主页显示 0 条，多为以下七种原因之一。

## 七种原因

1. **是个人账号**：只有公共主页能投广告。公共主页有「主页透明度」「赞 / 关注者」和类别；个人账号有「好友」。`facebook.com/61xxxxxxxxxxxxx`、`profile.php?id=…` 两者都会用，需打开确认。
2. **国家选错**：先改为「所有国家 / 地区」。
3. **用别的主页投**：如 Brand US、Brand UK 分区主页或多主页轮投；点广告上的主页名，或用品牌名、产品名关键词搜。
4. **已停投**：非政治类停投后通常消失，欧盟广告保留约一年；要在投时保存（见[Facebook 广告的图片和视频怎么保存下来](12-download-facebook-ad-creatives.md)）。
5. **关键词只在画面里**：只匹配文案（见[广告资料库关键词搜索技巧](04-ad-library-search-tips.md)）。
6. **刚上线或被拒**：未过审的还没出现；被拒、下架的不显示；主页被删或受限则全部不可见。
7. **帖子未付费推广**：加热的帖子算广告；纯自然流量帖子不在资料库。

## 排查顺序

1. 确认是带「主页透明度」的公共主页。
2. 从透明度点「前往广告资料库」。
3. 国家改「所有国家 / 地区」，状态改「全部」。
4. 仍为 0：没在投或挂在别的主页，用品牌名关键词搜。
