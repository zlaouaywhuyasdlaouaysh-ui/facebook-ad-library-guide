# 广告资料库编号（Library ID）是什么，怎么用编号直接打开广告

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《广告资料库编号（Library ID）是什么，怎么用编号直接打开广告》的精简版，完整图文版见文末链接。

每条广告有一串十几位的资料库编号（Library ID），凭它可直接打开广告。

## 位置与用法

- 广告卡片顶部和广告详情顶部的「资料库编号：XXXXXXXX」。
- 链接格式：`https://www.facebook.com/ads/library/?id=资料库编号`，或在[广告资料库链接生成器](https://33.ci/tools/ad-library-link-generator?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide)选「单条广告」生成。

## 用途

- 素材库表格：记编号、主页名、开始日期、备注。
- 团队沟通不指错。
- 逐国核对投放国家（见[怎么看一条 Facebook 广告投放了哪些国家](20-check-ad-countries.md)）。
- 盯是否停投。

## 打开却没有结果

- 已停投且非欧盟、非政治类。
- 被下架或拒绝。
- 是同组的另一条：同素材组只用一条做代表，编号各不相同（见[广告资料库里「多个版本」「X 条广告使用此素材」是什么意思](08-ad-library-multiple-versions.md)）。
