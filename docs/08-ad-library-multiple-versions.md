# 广告资料库里「多个版本」「X 条广告使用此素材」是什么意思

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《广告资料库里「多个版本」「X 条广告使用此素材」是什么意思》的精简版，完整图文版见文末链接。

前者说明同一创意被多处加量，后者多为动态创意或动态商品广告。

## 「X 条广告使用此素材和文案」

- 素材文案完全相同的广告归为一组，只显示一条。
- 区别在广告组（受众、版位、国家、预算），多半因为跑出效果在加量；几十上百条的可视为核心素材。
- 「查看详情」/「查看摘要详情」可看每条的开始日期和平台。

## 「此广告有多个版本」

- **动态创意（DCO）**：多图、多文案、多标题自动组合；切换版本可见全部备选，适合拆文案（见[怎么拆解竞品的 Facebook 广告文案](15-analyze-competitor-ad-copy.md)）。
- **动态商品广告（DPA）**：素材来自商品目录，每次显示的商品可能不同。
- 轮播（Carousel）不同：一条广告内可滑动的多张卡片，人人可见全部。

## 用法

1. 对手主页全部广告，选「投放中」。
2. 先看条数最多的组。
3. 结合投放天数（见[怎么看一条 Facebook 广告投放了多久](13-how-long-ad-has-been-running.md)）：又久又多的即最赚钱素材。
