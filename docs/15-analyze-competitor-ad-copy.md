# 怎么拆解竞品的 Facebook 广告文案

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《怎么拆解竞品的 Facebook 广告文案》的精简版，完整图文版见文末链接。

拆文案要看清：对谁说、抓什么痛点、凭什么让人点。

## 先挑广告

- 投放 30 天以上且仍在投（见[怎么看一条 Facebook 广告投放了多久](13-how-long-ad-has-been-running.md)）。
- 「X 条广告使用此素材和文案」条数多（见[广告资料库里「多个版本」「X 条广告使用此素材」是什么意思](08-ad-library-multiple-versions.md)）。
- 同一主页反复出现的说法。

## 五个问题

| 问题 | 在文案里找什么 |
| --- | --- |
| 开头抓的是什么？ | 第一句话：一个痛点、一个反常识、一个数字，还是一个场景 |
| 对谁说？ | 文案里出现的人群：新手妈妈、养狗的人、上班族、送礼的人 |
| 卖点是什么？ | 产品解决了什么问题，和别人比好在哪 |
| 用什么证明？ | 用户评价、销量数字、前后对比、专家背书、退款保证 |
| 让人做什么？ | 行动按钮和最后一句：现在买、领折扣、看更多、限时 |

## 按角度归类

如狗胸背带有「不勒脖子」「防爆冲」「好看拍照」等角度。条数多、投得久的角度被验证过；对手扎堆时换个没人打的角度，或说得更具体。

## 其他要点

- 多版本（动态创意）广告逐个切换，可看到对手在 A/B 测的标题和文案，长期留下的说法多是赢家。
- 不同国家的文案常换卖点和语气，不是直译；归纳角度时用自己的话，避免翻译腔。
