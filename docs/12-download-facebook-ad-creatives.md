# Facebook 广告的图片和视频怎么保存下来

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《Facebook 广告的图片和视频怎么保存下来》的精简版，完整图文版见文末链接。

资料库没有下载按钮，广告停投后通常会消失，看到好素材要当场保存。

## 单张图片

点「查看广告详情」打开大图，右键「图片另存为」；轮播广告逐张切换保存；手机上长按保存。

## 视频

1. 打开详情让视频播放，右键「视频另存为」。
2. 没有该选项时：在视频上右键两次调出浏览器自带菜单；或按 F12 打开「网络」面板，筛选「媒体」，播放后在新标签页打开视频请求再保存。

资料库的素材地址有时效，只存链接过几天就打不开。

## 同时记下

| 信息 | 例子 |
| --- | --- |
| 主页名称 | Nova Beauty |
| 资料库编号 | 每条广告唯一的编号，在卡片上 |
| 开始投放日期 | 2026-10-12 |
| 保存时是否还在投、已投多少天 | 投放中，21 天 |
| 文案和标题 | 复制完整文案 |
| 落地页链接 | 点广告按钮后的链接 |

有了这些才能事后判断是否爆款（见[怎么判断一条 Facebook 广告是不是爆款](11-how-to-spot-winning-facebook-ads.md)）。

## 批量留存

- 只存重点：筛「投放中」+「视频」，保存跑得最久的 10–20 条。
- 用抓取工具把整个主页抓成记录，导出含文案、日期、链接的表格并下载素材。

## 版权边界

素材只用于研究开头、节奏、卖点和文案结构，不要直接投放：原作者可向 Meta 举报，广告被拒、主页受限；品牌、模特、音乐各有授权问题。应学结构后用自己的产品重拍。
