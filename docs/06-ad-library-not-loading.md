# Facebook 广告资料库打不开、一直转圈、要求登录怎么办

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《Facebook 广告资料库打不开、一直转圈、要求登录怎么办》的精简版，完整图文版见文末链接。

多为网络或浏览器问题，按顺序排查。

## 排查步骤

1. **网络**：先试 `facebook.com`；用代理的换节点，同一 IP 请求过多会被限速（转圈、加载一半）。
2. **弹登录框**：IP 被判异常就换网络或节点；残留过期登录就用无痕窗口。不建议用常用个人号或广告号登录。
3. **空白或筛选点不动**：关广告拦截 / 隐私插件后刷新；换最新版 Chrome / Edge 或清 `facebook.com` 缓存；用电脑。
4. **加载一半停住**：回滚再下滚或刷新；结果太多就缩小范围（见[广告资料库关键词搜索技巧](04-ad-library-search-tips.md)）。
5. **能打开但搜不到**：见[为什么在广告资料库里搜不到某个主页或广告](05-why-ads-not-showing-in-ad-library.md)。

## 少开资料库

常用搜索可用[广告资料库链接生成器](https://33.ci/tools/ad-library-link-generator?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide)生成链接收藏；长期盯对手可用服务器端定时抓取的监控工具，不受本地网络影响。
