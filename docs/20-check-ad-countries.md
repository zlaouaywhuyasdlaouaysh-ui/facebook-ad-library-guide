# 怎么看一条 Facebook 广告投放了哪些国家

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《怎么看一条 Facebook 广告投放了哪些国家》的精简版，完整图文版见文末链接。

普通商业广告没有国家列表，欧盟以外的市场需靠国家筛选查出。

| 广告投到哪里 | 详情里能看到的地区信息 |
| --- | --- |
| 欧盟国家 | 「欧盟广告透明度」中按国家的覆盖人数 |
| 政治和社会议题广告 | 按地区的展示数据 |
| 其他商业广告（美国、加拿大、澳大利亚、东南亚等） | 没有国家列表 |

## 方法一：逐国筛选

1. 记下详情里的「资料库编号」。
2. 搜到这条广告，依次切换国家：美国、英国、加拿大、澳大利亚……
3. 能搜到的国家就是投放国家。

可用[广告资料库链接生成器](https://33.ci/tools/ad-library-link-generator?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide)批量生成各国链接。

## 方法二：看主页整体

打开主页全部广告（见[如何查看某个 Facebook 主页的全部广告](03-view-all-ads-of-a-page.md)），先选「所有国家 / 地区」记总数，再看各重点国家条数，多的即主力市场。

## 方法三：系统代查

33.ci 同行库「查投放地区」输入广告编号，后台逐国查询。

## 注意

- 只能看出投没投，看不出各国花费。
- 停投后通常查不到（欧盟保留约一年）。
- 英文广告也常投欧洲、东南亚，别凭语言判断。
