# 怎么查看竞争对手正在投放的 Facebook 广告

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《怎么查看竞争对手正在投放的 Facebook 广告》的精简版，完整图文版见文末链接。

Meta 广告资料库免费公开所有在投广告，关键是先找到对手，再记录下来。

## 已知品牌名

1. **按主页名搜**：打开 `https://www.facebook.com/ads/library/`，选「所有国家 / 地区」「所有广告」，输入品牌名后不按回车，点下拉中带头像的主页。
2. **从官网或主页进**：主页「主页透明度」→「前往广告资料库」，可避开重名，最准确。
3. **从刷到的广告进**：点广告上的主页名，再走第 2 步。

## 未知对手：产品词反查

用英文产品词搜，如 `dog harness`、`no pull harness`，反复出现的主页就是同行。

- 国家选目标市场，状态选「投放中」，媒体类型选「视频」。
- 换说法：品类词、痛点词 `dog pulling on leash`、卖点词 `escape proof`。
- 品类词表：[宠物用品](16-pet-products-facebook-ads.md)、[女装](17-womens-apparel-facebook-ads.md)。

## 每个对手记一张表

| 记录项 | 用途 |
|-|-|
| 主页名称和链接 | 直接打开 |
| 投放中的广告数 | 放量还是收缩 |
| 跑得最久的 3–5 条 | 主力素材 |
| 素材形式（图片、视频、轮播） | 偏重形式 |
| 开头三秒 / 主标题 | 钩子 |
| 优惠和卖点 | 价格、包邮、赠品 |
| 落地页链接 | 产品页和价格 |

重点学哪些见[怎么判断一条 Facebook 广告是不是爆款](11-how-to-spot-winning-facebook-ads.md)。资料库不记录上新和停投，对手少可每周对比，多则用监控工具。
