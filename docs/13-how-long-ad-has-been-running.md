# 怎么看一条 Facebook 广告投放了多久

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《怎么看一条 Facebook 广告投放了多久》的精简版，完整图文版见文末链接。

不赚钱的广告一般不会长期投，投放时长是判断效果最可靠的信号之一。

## 开始日期在哪看

- 投放中：卡片写「XXXX 年 X 月 X 日开始投放」，天数 = 今天 − 开始日期。
- 已停投：卡片显示「开始日期 – 结束日期」，相减即总天数。

状态选「投放中」再按开始日期筛，可找出投了很久还没停的广告。

## 天数怎么看

| 投放天数 | 一般说明什么 |
| --- | --- |
| 少于 7 天 | 还在测试期，看不出好坏 |
| 7–30 天 | 过了测试，可能有效果，值得留意 |
| 30 天以上 | 大概率在赚钱，重点研究对象 |
| 90 天以上 | 长青素材，可以拆它的角度、开头、卖点 |

高客单价、回本周期长的产品测试期更长。

## 容易看错

- 好素材被复制成新广告重投，开始日期是新的；同素材多条、日期递增说明在加量。
- 「多个版本」「X 条广告使用此素材和文案」也是加量信号，见[广告资料库里「多个版本」「X 条广告使用此素材」是什么意思](08-ad-library-multiple-versions.md)。
- 暂停后重开只显示最初开始日期。

主页广告多时可整页抓取后按天数排序；其他爆款信号见[怎么判断一条 Facebook 广告是不是爆款](11-how-to-spot-winning-facebook-ads.md)。
