# 怎么判断一条 Facebook 广告是不是爆款

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《怎么判断一条 Facebook 广告是不是爆款》的精简版，完整图文版见文末链接。

资料库不公开花费和转化，但投放行为公开；广告主只会长期给赚钱的广告花钱，所以可用以下信号间接判断。

## 五个信号

| 信号 | 怎么看 |
| --- | --- |
| 投放天数长且还在投 | 今天 − 开始日期：7 天内多在测试；2–4 周值得关注；1 个月以上多为主力素材。大品牌常驻、低预算广告也会跑很久，需结合其他信号 |
| 素材被复制 | 「N 条广告使用这个素材和文案」，N 越大越在跑量 |
| 同角度反复出变体 | 同一卖点或开头隔几天出新剪辑、模特、文案，说明角度有效 |
| 多个主页投同款 | 产品被市场验证，但也说明竞争激烈，跟进需差异化 |
| 「多个版本」长期在投 | 版本多只说明在测；跑很久没停说明至少一套有效，逐个版本看 |

## 组合判断

| 情况 | 判断 |
| --- | --- |
| 投放 30 天以上 + 复制多条 | 高可能是爆款，优先研究 |
| 投放 30 天以上 + 只有 1 条 | 稳定在跑，可能预算不大 |
| 投放不到 1 周 + 同角度已有多版 | 对手在加码测试这个角度 |
| 投放不到 1 周 + 只有 1 条 | 刚开始测，记下来过几天再看 |

## 操作流程

1. 进入对手主页的全部广告（见[如何查看某个 Facebook 主页的全部广告](03-view-all-ads-of-a-page.md)），状态选「投放中」。
2. 找出开始日期最早的 10 条，记下天数和复制条数。
3. 点开详情，记下开头、卖点、优惠和落地页。
4. 保存素材（见[Facebook 广告的图片和视频怎么保存下来](12-download-facebook-ad-creatives.md)）。
5. 一周后复查哪些停了、哪些还在、新增了什么。资料库不保存这个过程，需定期自己记录或用监控工具自动记录。

学结构、角度和节奏即可，别直接拿别人的视频和图片投放，可能因侵权被拒、主页受限。
