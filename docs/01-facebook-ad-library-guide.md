# Facebook 广告资料库怎么用：从打开到看懂一条广告

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《Facebook 广告资料库怎么用：从打开到看懂一条广告》的精简版，完整图文版见文末链接。

Meta 官方的公开广告查询工具，可查 Facebook、Instagram、Messenger、Audience Network 在投广告的素材、文案和开始日期。

## 打开

`https://www.facebook.com/ads/library/`，无需登录或广告账户；电脑比手机方便。

## 三步搜索

1. **国家 / 地区**：不确定选「所有国家 / 地区」；**广告类别**选「所有广告」（政治类与卖货无关）。
2. **搜索**：输入主页名后点下拉中的主页，看其全部广告；或输入产品词回车，默认模糊匹配，加英文双引号为精确匹配。
3. **筛选条件**：

| 筛选项 | 用途 |
|-|-|
| 投放状态 | 投放中 / 已停投 / 全部 |
| 语言 | 多语种市场 |
| 平台 | 对手主投哪里 |
| 媒体类型 | 只看视频等 |
| 展示日期 | 节日档期 |

## 广告卡片要点

- 投放状态 + 开始日期：算出已跑天数，越久越可能赚钱（见[怎么判断一条 Facebook 广告是不是爆款](11-how-to-spot-winning-facebook-ads.md)）。
- 平台图标、资料库编号（唯一）。
- 「这条广告有多个版本」：多套素材或文案。
- 「N 条广告使用这个素材和文案」：被复制成多条，通常在加量。

## 能看到什么

| 信息 | 商业广告 | 投放到欧盟的广告 |
|-|-|-|
| 素材、文案、按钮、落地页链接 | 能 | 能 |
| 开始投放日期、投放平台 | 能 | 能 |
| 花费、点击、转化 | 不能 | 不能 |
| 覆盖人数、年龄 / 性别 / 地区分布 | 不能 | 能 |
| 停投后能否查到 | 通常查不到 | 保留约一年 |

## 常见问题

- 搜不到主页：先确认是公共主页、国家没选错。
- 下载素材：无下载按钮，见[Facebook 广告的图片和视频怎么保存下来](12-download-facebook-ad-creatives.md)。
- 资料库只显示当下状态，不记录变化，持续跟踪需定期对比或用监控工具。
