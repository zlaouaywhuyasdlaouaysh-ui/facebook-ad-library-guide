# 广告资料库关键词搜索技巧：搜得准、搜得全

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《广告资料库关键词搜索技巧：搜得准、搜得全》的精简版，完整图文版见文末链接。

先模糊后精确、用目标市场语言、多角度换词、配合筛选。

## 匹配方式

- `dog harness`：模糊匹配，词都出现即可，结果多但杂。
- `"no pull dog harness"`：精确匹配，须原样出现，结果少但准。

## 语言与国家

- 美、英、澳用英文；德、法、西、日用当地语言；中文基本只搜到投给华人的广告。不确定可查当地亚马逊同类标题。
- 「所有国家 / 地区」摸品类，单个国家聚焦市场；两种都搜能看出哪里更热。

## 筛选

投放状态「投放中」、媒体类型「视频」、语言（如美国的西班牙语广告）、展示日期（如黑五前一个月）。

## 换角度搜（以宠物胸背带为例）

| 角度 | 例子 |
|-|-|
| 品类词 | dog harness |
| 细分款 | no pull harness、escape proof harness |
| 痛点 | dog pulls on leash |
| 场景 | dog hiking、car safety dog |
| 促销话术 | free shipping、buy 2 get 1 加品类词 |
| 竞品品牌名 | 搜对手品牌，找到它和模仿者 |

品类词表：[宠物用品](16-pet-products-facebook-ads.md)、[女装](17-womens-apparel-facebook-ads.md)。

## 搜不准的原因

- 词只在图片 / 视频画面里（只搜文案）。
- 单复数、拼写：`legging` 与 `leggings` 都试。
- 词太泛：`dress` 加款式或场景词。
- 国家选窄了。

搜到后逐个看反复出现的主页；值得长期看的关键词可收藏结果页链接或用监控工具跟踪。
