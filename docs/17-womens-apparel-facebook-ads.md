# 女装 Facebook 爆款广告怎么找

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《女装 Facebook 爆款广告怎么找》的精简版，完整图文版见文末链接。

女装款式快、季节性强，直接搜 dress 结果太多，要按品类、场景、人群拆开搜。

## 代表性搜索词

以下各取一半，完整词表见完整版。

| 维度 | 英文搜索词 |
| --- | --- |
| 连衣裙 | maxi dress、wrap dress、sweater dress |
| 裤装 | wide leg pants、tummy control leggings |
| 上衣 | oversized sweater、cardigan |
| 外套 | trench coat、shacket |
| 泳装 | one piece swimsuit、tummy control swimsuit |
| 塑身内衣 | shapewear、body shaper |
| 套装 | two piece set、lounge set |
| 场景 | wedding guest dress、vacation outfits、work outfits、date night dress |
| 风格/人群 | boho dress、plus size dress、maternity dress |

场景词的文案更有针对性；人群词竞争通常比大词小。搜索技巧见[广告资料库关键词搜索技巧：搜得准、搜得全](04-ad-library-search-tips.md)。

## 素材与文案

- 素材：试穿视频（最常跑量）、多尺码展示、面料特写、轮播多色、塑身类前后对比。
- 文案角度：舒适、遮肉显瘦（tummy control）、一衣多穿、社会认同（sold out 3 times）、限时优惠。

## 季节节点（美国市场）

| 时间 | 对手在推什么 |
| --- | --- |
| 1–2 月 | 情人节约会装、度假装 |
| 3–4 月 | 春装连衣裙、复活节 |
| 4–6 月 | 泳装、母亲节、婚礼宾客装 |
| 7–8 月 | 返校、早秋单品 |
| 9–10 月 | 毛衣、开衫、外套 |
| 11 月 | 黑五、网一大促 |
| 12 月 | 节日派对裙 |

对手通常提前 4–8 周测下一季款。

## 看款注意

- 看投放天数而非点赞：3 周以上还在投更说明赚钱（见[怎么判断一条 Facebook 广告是不是爆款](11-how-to-spot-winning-facebook-ads.md)）。
- 多个主页同投一款多为热门供货款，需差异化。
- 设计、印花、模特图有版权，别直接用（见[Facebook 广告的图片和视频怎么保存下来](12-download-facebook-ad-creatives.md)）。

下一步：找 5–10 个同行主页看全部广告（见[如何查看某个 Facebook 主页的全部广告](03-view-all-ads-of-a-page.md)），每周看一次新增。
