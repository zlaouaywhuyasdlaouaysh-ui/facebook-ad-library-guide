# 怎么找 Facebook 主页编号（Page ID）

> 本章是 [33.ci](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide) 教程《怎么找 Facebook 主页编号（Page ID）》的精简版，完整图文版见文末链接。

Page ID 是公共主页唯一的数字编号，改名不变，比按名称查广告更准。

## 三种方法

1. **资料库链接（最快）**：进入主页广告列表，地址栏里 `view_all_page_id=` 后的数字；也可粘进[广告资料库链接生成器](https://33.ci/tools/ad-library-link-generator?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide)「解析」框。
2. **主页透明度**（Page transparency）→「查看全部」：含编号、创建日期、改名记录。
3. **主页链接**：`facebook.com/61551234567890`、`profile.php?id=100089…` 也可能是个人账号，有「主页透明度」才是公共主页。

## 用编号打开全部广告

```
https://www.facebook.com/ads/library/?active_status=all&ad_type=all&country=ALL&search_type=page&view_all_page_id=主页编号
```

或在链接生成器选「主页全部广告」。
