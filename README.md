## 中英术语对照

资料库界面是什么语言取决于你的 Facebook 语言设置，看英文教程或和海外同事沟通时用得上。

| 中文界面 | 英文界面 | 说明 |
|:--|:--|:--|
| 广告资料库 | Ad Library / Meta Ad Library | `facebook.com/ads/library` |
| 资料库编号 | Library ID | 每条广告唯一的数字编号 |
| 主页编号 | Page ID | 每个公共主页唯一的数字编号，改名不变 |
| 主页透明度 | Page transparency | 主页编号、创建日期、改名记录 |
| 投放中 / 已停投 | Active / Inactive | 链接参数 `active_status` |
| 所有广告 | All ads | 商业广告选这个 |
| 社会议题、选举或政治 | Issues, elections or politics | 公开数据更多，但和卖货无关 |
| 筛选条件 | Filters | 语言、平台、媒体类型、展示日期 |
| 查看广告详情 | See ad details | 完整文案、所有版本、广告主信息 |
| 此广告有多个版本 | This ad has multiple versions | 同一条广告配了多套素材或文案 |
| N 条广告使用此素材和文案 | N ads use this creative and text | 同一套素材被复制成多条广告 |
| 动态创意 | Dynamic creative (DCO) | 系统自动组合素材和文案测试 |
| 动态商品广告 | Dynamic product ads (DPA) | 按商品目录自动生成 |
| 轮播 | Carousel | 多张图片或视频左右滑动 |
| 覆盖人数 | Reach | 只有欧盟和政治类广告公开 |

## 配套工具

- [facebook-ad-library-tools](https://github.com/zlaouaywhuyasdlaouaysh-ui/facebook-ad-library-tools)：命令行和油猴脚本。生成、解析资料库链接，从文本里批量提取广告编号和主页编号。
- [Facebook 广告资料库链接生成器（在线）](https://33.ci/tools/ad-library-link-generator?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide)
- [Facebook 广告状态查询（在线）](https://33.ci/tools/ad-status-checker?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide)：输入广告编号，看还在不在投、投了多少天。

资料库只显示当下的状态，不会告诉你对手昨天到今天变了什么。要持续跟踪新上、停投、改素材、改文案，可以用 [33.ci 广告监控](https://33.ci/?utm_source=github&utm_medium=referral&utm_campaign=fb-ad-library-guide)。
